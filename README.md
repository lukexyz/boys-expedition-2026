# Dolomites 2026 — The Boys' Expedition

Interactive master map for the trip, 18–23 August 2026.

**Live map → https://lukexyz.github.io/boys-expedition-2026/**

Five hikes, three basecamps, one hire car, plotted on a single map with
photo pop-outs, day-by-day briefings and route overlays.

| | |
|---|---|
| **Hike 1** | Nuvolau & Averau loop from Passo Giau — 8.8 km / 620 m |
| **Hike 2** | Lagazuoi WWI tunnels *or* Piz Boè 3,152 m summit (toggle in the legend) |
| **Hike 3** | Tre Cime di Lavaredo loop + Cadini di Misurina — date-locked to Thu 20 Aug |
| **Hike 4** | Torri del Vajolet to Rifugio Re Alberto — 14.7 km / 950 m |
| **Hike 5** | Seceda ridgeline |

Nights: San Vito di Cadore (1–3) → Rifugio Re Alberto (4) → Rifugio Fermeda (5).

### Notes
Routes are indicative lines drawn through the real waypoints for orientation —
they are **not** surveyed GPX. Download the proper tracks from the linked guides
and carry them offline.
